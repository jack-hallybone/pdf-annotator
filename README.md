# pdf-annotator

<https://jack-hallybone.github.io/pdf-annotator/>

## Intent

To provide a lightweight PDF viewer and annotator for reading and taking notes,
including freehand ink and other common annotation types. It should perform like
a complete and robust — but lightweight — PDF program, with sidebar, tabbed and
split views, interoperable file reading and writing, and basic file
manipulation. It should work offline, and keep the reader's files to themselves.

## Authorship

This project was written by AI, directed and reviewed by a human.
